# py\_ad\_MHK\_RM1\_Fixed

This test is based on the fully coupled OpenFAST regression test case `MHK_RM1_Fixed`
(a fixed-bottom MHK tidal-current turbine, 2 blades, based on the RM1 rotor). Its
purpose is to verify the AeroDyn C-bindings blade **added-mass** output, which is only
nonzero for MHK turbines.

The blade motions are generated by running the coupled `MHK_RM1_Fixed` OpenFAST case with
the `WrVTK` animation option (`VTK_type = 3`, all mesh fields). The resulting per-timestep
AeroDyn interface-mesh VTK files (hub, nacelle, blade roots, and blade line meshes) are
copied into `vtkRef/` with the base names the Python driver expects. The driver reads
these motions and passes them to AeroDyn and InflowWind through the C-bindings interface
from Python.

At each timestep the driver calls `ADI_C_CalcOutput_and_AddedMass` instead of the usual
`ADI_C_CalcOutput`. This returns:

* the normal output channels (written to `py_ad_driver.out`, compared against the
  baseline by the regression test), and
* the per-node 6x6 blade added-mass matrices in the global frame.

The driver verifies that the peak added-mass magnitude is nonzero (it raises an error and
fails the test otherwise) and writes the final-timestep per-node matrices to
`py_ad_driver_addedmass.out` for inspection.

Notes:

* Tower influence/aero (`TwrPotent`, `TwrShadow`, `TwrAero`) and the generalized support
  structure (GS) models are disabled in `ad_primary.dat`; these are not supported through
  the AeroDyn C-bindings interface (no tower/GS motions or loads are transferred).
* Sea water properties are used (density 1025 kg/m^3, kinematic viscosity 1.06e-06 m^2/s,
  water depth 50 m). Added mass depends only on the blade geometry and node kinematics, so
  it is independent of the inflow and wave conditions.
