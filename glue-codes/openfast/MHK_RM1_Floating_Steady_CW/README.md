RM1 floating marine turbine, steady current, rotor turning clockwise

From MHK_RM1_Floating, with the inflow changed from a turbulent box to steady
uniform current so the two cases form a symmetry pair.

With uniform inflow and a structure symmetric about the vertical plane, a
counter-clockwise rotor is physically the same machine as the clockwise one, so
every channel must either match or be an exact negation. This is the only
mirrored case that reaches the MHK buoyancy path, which is skipped entirely for
a wind turbine, and it is where the centre-of-buoyancy offset BlCenBt is
exercised: BlSwpAC is zero at every station of this blade, so no other mirrored
quantity in the blade geometry does anything here.
